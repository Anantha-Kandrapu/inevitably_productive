To run Chrome's local Gemini Nano on-device:

  1. Open chrome://flags in a new tab.
  2. Set #prompt-api to Enabled.
  3. Set #optimization-guide-on-device-model to Enabled BypassPerfRequirement.
  4. Relaunch Chrome. Check chrome://components for "Optimization Guide On Device Model" download.
